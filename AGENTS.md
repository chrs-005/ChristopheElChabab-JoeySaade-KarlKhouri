# Repository working agreement

The course brief is authoritative. This is a backend-only student project. AI assistance must be disclosed; do not fabricate execution or student contributions, or produce all nine services as an autonomous submission.

After every work session:

1. Read `docs/TASKS.md` and the relevant owner's handoff. Identify the active member from explicit instructions or reliable context. If unknown, do shared planning/review and ask before attributing implementation.
2. Pick an unblocked task within that member's ownership. Make focused changes without overwriting teammates' work.
3. Run appropriate checks and record their actual results.
4. Update `docs/TASKS.md` in the same change set. Update the owner's handoff with changes, files/endpoints, checks and results, remaining work, blockers, and what teammates can integrate.
5. Update API contracts, Postman, and service docs when behavior changes. Update `docs/CONTRIBUTIONS.md` with factual work and AI assistance.
6. End with completed work and the next available task.

Task states: TODO; IN_PROGRESS; BLOCKED; IMPLEMENTED (code exists); VERIFIED (relevant checks passed); DONE (implementation, integration, docs, Postman, and required real evidence complete). Missing evidence means below DONE. Only add commit or PR references after they exist. Each student commits and pushes with their own account; never impersonate an author.

Every API route must include the confirmed owner's full name as a URL-safe prefix. Preserve the brief's endpoint suffix. Confirmed names: Joey Saade, Karl Khoury, Christophe El Chabab.
