# Joey Saade screenshot destination

Save Joey's real Postman request-detail and SQLite PNG screenshots under this directory, using the 32 exact relative filenames in `../joey-evidence.tex`. Each filename is just its two-digit number, such as `01-Users/11.png`. The report loads any matching image automatically and displays a named pending box for every missing image. Existing folder Runner images remain supplementary evidence. Do not create mock images or include tokens, passwords, service keys, `.env`, or a database file in this directory.

Use the capture order and SQLite queries in `../JOEY-SCREENSHOT-GUIDE.md`. Keep screenshots from the populated database before running the collection's Cleanup folder.
