Creation returns 201; successful reads, searches, status changes and deletions return 200, and a repeated audit event ID returns 200 with the stored entry. Missing or invalid authentication, or a wrong service key, returns 401. Insufficient permission returns 403, absent records return 404, and duplicate step numbers, invalid status transitions and protected deletions return 409. Invalid input, out-of-order steps and invalid date filters return 422. A report whose upstream service is unreachable returns 503, and one whose upstream replies with an error returns 502. Error bodies carry a status and message. The importable collection and credential-free template are \texttt{postman/karl.collection.json} and \texttt{postman/karl.environment.template.json}. The administrator's credentials and the audit service key are entered only in a private local environment.
