\subsection*{Joey Saade API routes}
All suffixes in this table follow \texttt{/api/Joey-Saade}. Administrator, Analyst and Auditor refer to the corresponding Security roles; Employee means Regular Employee. The first 18 rows are the required routes. The last two document implemented supporting routes.

Creation returns 201; successful reads, updates and deletions return 200. Missing or invalid authentication returns 401, insufficient permission returns 403, absent records return 404, duplicate or referenced records return 409, and invalid input returns 422. Error bodies carry a status and message, with field errors for request-shape validation. The importable collection and credential-free template are \texttt{postman/joey.collection.json} and \texttt{postman/joey.environment.template.json}. Credentials and bearer tokens are entered only in a private local environment.
